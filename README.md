# 🧬 DNA Sequence Analyzer

An interactive web app built with **Python** and **Streamlit** to analyze DNA sequences, calculate GC/AT content percentages, and generate RNA transcription and Reverse Complement strands.

## 📊 Features & Functional Highlights
- **Data Integrity & Validation:** Validates raw DNA input for correct nucleotide bases (`A`, `T`, `C`, `G`).
- **Basic Statistics:** Calculates total sequence length (`bp`), **GC Content (%)**, and **AT Content (%)**.
- **Nucleotide Base Distribution:** Real-time frequency counting of bases.
- **Sequence Transformations:** Automatically outputs **RNA Transcription** and **Reverse Complement** sequences.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Streamlit
- **IDE:** PyCharm
